# Competitors (researched 2026-09-20 via Chrome Web Store search snippets)

Caveat: ratings come from search-result snippets; user counts and exact permission lists were not verifiable through search and must be re-checked on each listing before any marketing claim. Weaknesses marked (typical) are patterns for the category, not confirmed per extension.

| Extension | What it does | Rating (seen) | Weaknesses |
|---|---|---|---|
| [OpenDyslexic for Chrome](https://chromewebstore.google.com/detail/opendyslexic-for-chrome/cdnapgfjopgaggbmfgbiinmmbdcglnam) | Forces OpenDyslexic on all pages | 4.1 | Font only: no contrast, size or read-aloud, so users need several extensions. Users report missing symbol glyphs. Whole-page font override can break icon fonts (typical). Likely all-sites access (typical). |
| [Dyslexia Friendly](https://chromewebstore.google.com/detail/dyslexia-friendly/miepjgfkkommhllbbjaedffcpkncboeo) | OpenDyslexic or Comic Sans, paragraph background colours, mouse reading ruler | n/a | Open source but no TTS or contrast mode; ruler and colours add surface area beyond core needs. |
| [FocusFlow: Open Dyslexic Font & Ruler](https://chromewebstore.google.com/detail/open-dyslexic/kgifnbinkpgeomapdbmgibiofenahlkk) | Font plus ruler | n/a | Font/ruler only; rebranded listing, so trust signals unclear. |
| [Dyslexie Font](https://chromewebstore.google.com/detail/dyslexie-font-dyslexia-ac/jphdkcjkapjfojcjajeeomimmihnghjp) | Font, size, spacing, line spacing, background colours | n/a | Proprietary commercial font brand, typically with paid tiers (typical); many controls, heavier UI. |
| [Dyslexia Helper](https://chromewebstore.google.com/detail/dyslexia-helper/mebbcokadkflofmigccphgchlenjeoio) | One-click dyslexia-friendly formatting | n/a | No read-aloud or contrast; persistence per site unclear. |
| [Read Aloud](https://chromewebstore.google.com/detail/read-aloud-a-text-to-spee/hdhinadidafjejdhmfkjgnolgimiaplp?hl=en) | TTS for pages/PDFs, browser and cloud voices | 3.7 | Good: open source, no all-sites permission. Weak: cloud "Premium Voices" need Google sign-in and paid usage beyond free tier; no visual adjustments; dense UI. |
| [High Contrast](https://chromewebstore.google.com/detail/high-contrast/djcfdncoelnlbldjfhinnjlhdjlikmph?hl=en) | Colour-inversion filters on all pages | 3.7 | Inversion also inverts images/video and breaks page colours; no text size. |
| [High Contrast V3](https://chromewebstore.google.com/detail/high-contrast-v3/feifjeidnhmidmfiplikffpkgkmjlmbl) | 12 contrast modes, per-site config, shortcuts | 3.0 | Complexity (12 modes); low rating suggests page breakage. |
| [High Contrast for Chrome](https://chromewebstore.google.com/detail/high-contrast-for-chrome/chgaobeoienmhefkaoojgbdfkiaokjhg) | Bold contrast themes | 4.2 | Contrast only. |
| [Accessibility for ALL](https://chromewebstore.google.com/detail/accesibility-for-all/cilafiaffhgjmceeokfcmdgfihibmmoa) | Toolbar: font size, dyslexia mode (Arial), dark mode, saturation | n/a | Closest rival (multi-feature), but dyslexia mode is just Arial, not a dyslexia-designed font; no TTS listed. |

## Gap AccessEase fills
One extension covering size + contrast + dyslexia font + reduced motion, with no account and no permanent all-sites permission by default.
